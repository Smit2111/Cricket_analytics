# Cricket_analytics

An interactive Streamlit-based dashboard for analyzing IPL cricket match data, providing insights into team performance, match outcomes, toss strategies, and venue trends through dynamic visualizations.

This project helps users explore cricket data in an intuitive way, enabling deeper understanding of match patterns and team comparisons.

Dataset
IPL dataset (IPL DATASET.csv)
Includes:
Teams & match results
Toss decisions & winners
Win margins (runs/wickets)
Venue information
Player of the match

Key Insights
Identify top-performing teams
Analyze toss impact on match outcomes
Discover most popular venues
Compare team vs team performance
Understand win margins and match trends

How to Run
pip install -r requirements.txt
streamlit run app.py
